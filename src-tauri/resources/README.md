# Recursos de terceros (no versionados)

Esta carpeta la crea `tools/fetch-windows-deps.*` y contiene `libmpv-2.dll`
para los paquetes de Windows. En Linux se usa `libmpv` del sistema.

No se sube al repositorio por tamaño. Para obtenerlo:

```bash
./tools/fetch-windows-deps.sh
```

o, desde PowerShell:

```powershell
./tools/fetch-windows-deps.ps1
```
